# Design decisions

Upstream facts checked 2026-10-30. Each entry records an ambiguity or upstream change and the choice made.

| # | Topic | Decision | Reason |
|---|---|---|---|
| 1 | **Scope: "all Windows PCs"** | HackWizard *runs* on every Windows 10/11 PC, but builds an EFI only where macOS can work: x86-64 Intel/AMD + UEFI + a macOS-drivable GPU + a usable disk. Everything else is **blocked with a specific explanation** (ARM64, Legacy BIOS, Intel ≤ Ivy Bridge, Atom/Celeron N, AMD FX, Intel 11th-gen+ and Ryzen 6000+ laptops whose iGPUs have no macOS driver). | Building an EFI that can't boot or can't show a desktop would waste the user's time and data. Dortania's GPU guide lists Haswell/Broadwell as max Monterey; Alder Lake laptops are not possible due to the iGPU. |
| 2 | **No hardware logic in code** | The rules engine is generic: device/disk/cpu/system/always scopes, priorities, per-device exclusive `group`s, `provides`/`requires`/`recommends` capabilities, SMBIOS proposals and `maxDarwin` limits. All PC-specific knowledge lives in JSON. | Open-source contributors can add hardware without touching C#. The same KB drives the app and the Python simulator. |
| 3 | **Two implementations** | `tools/kb_tool.py` mirrors the C# rules engine. CI generates `*.expected.json` with Python; xUnit asserts C# produces the same for every profile. | No .NET needed to iterate on rules. Divergence between the two shows up as a failing test. |
| 4 | **SMBIOS selection** | Per CPU generation and form factor, with `hasCapability: gpu-dgpu` choosing dGPU models (iMac18,3, MacPro7,1). macOS versions are gated by Apple's supported models for that SMBIOS (macos.json) and by iGPU `maxDarwin`. The recommendation is the newest allowed version without warnings. | Matches Dortania's SMBIOS guide without SMBIOS spoofing or root patches (OCLP-style patching is out of scope). |
| 5 | **Intel iGPU** | `AAPL,ig-platform-id` per generation from Dortania (laptop/desktop/headless), plus device-id spoofs for UHD 620 (Kaby R), Comet Lake UHD and HD 4400. The iGPU is identified by device path `PciRoot(0x0)/Pci(0x2,0x0)`; Intel discrete (Arc) is anything behind a bridge. | iGPU is always at 00:02.0 on Intel client platforms. |
| 6 | **Intel CPU quirks** | Base Intel quirks + generation overlays (Coffee laptop MAT quirks; 300/400-series desktop DevirtualiseMmio/ProtectUefiServices; Ice Lake SetupVirtualMap off; Comet U62, Rocket and Alder+ CPUID spoofs; ProvideCurrentCpuInfo for Alder+). AppleXcpmCfgLock is always set (safe whether or not CFG Lock is unlocked). | Dortania per-generation config pages. CFG Lock state can't be read reliably from Windows. |
| 7 | **CpuTopologyRebuild** | Not added automatically. | Third-party (b00t0x). Optional performance improvement for Alder/Raptor; not needed to boot. |
| 8 | **AMD** | AMD_Vanilla with core count + Dortania AMD quirks for families 17h/19h; 1Ah marked experimental; 15h/16h blocked. B550/A520 boards with ACPI0007 CPUs get a warning about SSDT-CPUR (not generated). | SSDT-CPUR needs per-board processor declarations; a wrong one can stop the boot. |
| 9 | **NootedRed** | Only for Raven-family Vega iGPUs and only when no supported AMD dGPU is present; excludes WhateverGreen. Downloaded for the user, never redistributed. | ChefKiss prerequisites and license (ChefKiss Open Knowledge License, with restrictions including AI-related ones). Review it before redistributing anything that contains the kext. |
| 10 | **Unsupported GPUs** | NVIDIA, Intel Arc and unsupported AMD dGPUs get `disable-gpu` DeviceProperties instead of the global `-wegnoegpu`. | Disables only the unsupported card, so a supported dGPU in the same machine keeps working. |
| 11 | **Wi-Fi on Sequoia/Tahoe** | itlwm + HeliPort. AirportItlwm on Monterey/Ventura/Sonoma via `kextVariants`. | Latest official itlwm (v2.3.0) has AirportItlwm builds only up to Sonoma 14.4; Sequoia builds exist only in unofficial forks. |
| 12 | **Audio layouts** | One curated list (ALC257). Every other codec gets its layout-ids from AppleALC's own `Resources/*/Info.plist` (release source archive). The first layout is used and the rest are listed in the post-install guide. Unknown codec → layout 1 with a warning. | Avoids maintaining a stale codec table; AppleALC is the source of truth. |
| 13 | **SSDTs** | Generated from real ACPI paths read in Windows (`DEVPKEY_Device_BiosDeviceName`) plus DSDT probes (`STAS`, `RHUB`): EC-USBX, PLUG (Processor or ACPI0007 object), AWAC (STAS switch or fake RTC0), PMC (300-series desktop), RHUB (Ice Lake), PNLF, ALS0, XOSI (I2C). An SSDT whose path can't be determined is **skipped with a warning**, never guessed. Compiled by a built-in AML encoder; iasl optional for cross-checking. | Deterministic, testable, no bundled third-party binaries. |
| 14 | **SSDT-PLUG on Alder Lake+** | Not generated. | Dortania's PLUG targets Haswell–Comet; Alder+ uses ProvideCurrentCpuInfo. PLUG-ALT is left to post-install. |
| 15 | **Ethernet** | I225/I226/I210/I211 marked Partial without a kext. | Support depends on the revision, and the working drivers are third-party (not Dortania-listed official sources). |
| 16 | **Network for install** | `recommends: net-install` (provided by supported Ethernet rules) produces a warning that suggests USB-Ethernet or iPhone hotspot. | Online recovery needs a wired connection; many laptops have none. |
| 17 | **BIOS guide** | Model profiles (T495; generic ThinkPad), vendor key defaults for major OEMs/board makers, and generic settings filtered by `when` (CPU vendor, form factor, capabilities). Lenovo WMI apply works on any Lenovo whose profile maps settings. | HP/Dell also have WMI BIOS interfaces; adding them is a future provider. |
| 18 | **Recovery** | Native C# `macrecovery.py` port; board-ids from Dortania's table (Monterey `Mac-E43C1C25D4880AD6` … Tahoe `Mac-CFF7D910A743CAAF`). | |
| 19 | **USB layout** | GPT + one FAT32 partition (≤ 16 GB), native FAT32 formatter, diskpart fallback. | |
| 20 | **Licensing** | MIT for HackWizard's own code. No third-party binaries or macOS components in the repo or the EXE. Components are fetched at run time from upstream, each under its own license (`THIRD-PARTY-NOTICES.md`). | Keeps the project redistributable. |
| 21 | **KB updates** | Embedded KB, extracted to `%ProgramData%`; replaced when a newer HackWizard ships a newer KB; online updates via `manifest.json` (SHA-256 per file + optional ECDSA signature). Forks set their own `updateUrl` and key. | |
| 22 | **Golden snapshots** | Must be approved once on a Windows build machine (`build.ps1 -ApproveSnapshots`) and committed. | They are produced by the C# writer and can't be generated in the KB-only CI job. |
